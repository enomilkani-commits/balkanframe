# Balkan Frame

The Balkan film industry, in one frame: funds, cash rebates, deadlines, festivals, schools and labs, people, achievements, heritage, locations, production and rental companies, and a map, across Albania, Bosnia and Herzegovina, Bulgaria, Croatia, Greece, Kosovo, Montenegro, North Macedonia, Romania, Serbia and Slovenia.

A static site (HTML, CSS, JavaScript). No build step: Netlify publishes the repository root as it is.

- `data.js`, `data2.js`: all listings
- `news.json`: the two news ribbons, refreshed daily
- `img/`: logos and interview photos
